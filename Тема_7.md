```python
def longest_words(file):
    with open(file, encoding='utf-8') as f:
        words = f.read().split()
        max_length = len(max(words, key=len))
        for word in words:
            if len(word) == max_length:
                sought_words = word
    if len(sought_words) == 1:
        return sought_words[0]
    return sought_words

print(longest_words('input.txt'))

Результатом выполнения задачи будет: скриншот файла со статьей, листинг кода, и вывод в консоль, в котором будет указана вся необходимая информация.

```python
def analyze_text(filename):
    with open(filename, 'r', encoding='utf-8') as f:
        text = f.read().lower()

    # оставляем только буквы, цифры и пробелы
    clean = ''
    for ch in text:
        clean += ch if ch.isalnum() or ch == ' ' else ' '

    words = clean.split()
    total = len(words)

    # считаем вручную количество каждого слова
    counts = {}
    for w in words:
        counts[w] = counts.get(w, 0) + 1

    # ищем самое частое слово
    most_word, most_count = '', 0
    for w, c in counts.items():
        if c > most_count:
            most_word, most_count = w, c

    print(f"Общее количество слов: {total}")
    print(f"Самое частое слово: «{most_word}» — {most_count} раз(а)")
    print("\nТоп-10 самых частых слов:")
    for w, c in sorted(counts.items(), key=lambda x: x[1], reverse=True)[:10]:
        print(f"{w}: {c}")

# пример вызова

```

### Напишите программу, которая получает на вход предложение, выводит его в терминал, заменяя все запрещенные слова звездочками * (количество звездочек равно количеству букв в слове). Запрещенные слова, разделенные символом пробела, хранятся в текстовом файле input.txt. Все слова в этом файле записаны в нижнем регистре. Программа должна заменить запрещенные слова, где бы они ни встречались, даже в середине другого слова. Замена производится независимо от регистра: если файл input.txt содержит запрещенное слово exam, то слова exam, Exam, ExaM, EXAM и exAm должны быть заменены на ****.

•	Запрещенные слова:

hello email python the exam wor is

•	Предложение для проверки:

Hello, world! Python IS the programming language of thE future. My EMAIL is....

PYTHON is awesome!!!!

•	Ожидаемый результат:

*****, ***ld! ****** ** *** programming language of *** future. My ***** **....

****** ** awesome!!!!

```python
def censor_text(sentence):
    with open('input.txt', 'r', encoding='utf-8') as f:
        banned = f.read().split()

    lower_sentence = sentence.lower()
    result = list(sentence)

    for bad in banned:
        bad_lower = bad.lower()
        start = 0
        while True:
            pos = lower_sentence.find(bad_lower, start)
            if pos == -1:
                break
            for i in range(pos, pos + len(bad_lower)):
                result[i] = '*'
            start = pos + 1

    print(''.join(result))
    
    
text = 'Hello, world! Python IS the programming language of thE future. My EMAIL is....\nPYTHON is awesome!!!!'
censor_text(text)

```

Использует цикл while с find() для поиска всех вхождений, игнорируя регистр, и выводит цензурированный текст, демонстрируя строковую манипуляцию для цензуры.
