## Лабораторная работа №5
### Для сопровождения первых лиц государства X нужен кортеж, но никто не может определиться с порядком машин, поэтому вам нужно написать функцию, которая будет сортировать кортеж, состоящий из целых чисел по возрастанию, и возвращает его. Если хотя бы один элемент не является целым числом, то функция возвращает исходный кортеж.

```python
def tuple_sort(tpl):
    for elm in tpl:
        if not isinstance(elm, int):
            return tpl
    return tuple(sorted(tpl))

if __name__ == '__main__':
    print(tuple_sort((5, 5, 3, 1, 9)))
    print(tuple_sort((5, 5, 2.1, '1', 9)))
```
### Результат.
![Меню](pic/pic5.png)

## Выводы

Функция `tuple_sort()` проверяет, все ли элементы кортежа являются целыми числами, с помощью `isinstance()`. Если условие выполнено, кортеж сортируется по возрастанию с использованием `sorted()` и возвращается как новый кортеж. В противном случае возвращается исходный кортеж, что предотвращает ошибки при работе с некорректными данными.

def remove_first_occurrence(tpl, element):
    try:
        index_to_remove = tpl.index(element)
        new_tpl = tpl[:index_to_remove] + tpl[index_to_remove + 1:]
        return new_tpl
    except ValueError:
        return tpl

print(remove_first_occurrence((1, 2, 3), 1))

Требуется создать словарь, который в качестве ключей будет принимать данные числа (т. е. ключи будут типом int), а в качестве значений – количество этих чисел в имеющейся последовательности. ```python
from collections import Counter

def get_top_three_counts(digit_string):
    int_list = [int(digit) for digit in digit_string]
    count_dict = Counter(int_list)
    top_three = count_dict.most_common(3)
    sorted_top_three = sorted(top_three, key=lambda item: item[0])
    result_dict = dict(sorted_top_three)
    return result_dict

test_string = "112333444455555678900" 
result = get_top_three_counts(test_string)
print(result)
```

Метод `most_common(3)` выбирает три наиболее часто встречающиеся цифры, которые затем сортируются по ключу (цифре) для упорядоченного вывода. Это эффективный способ анализа частотности данных.

## Самостоятельная работа №4
### Ваш хороший друг владеет офисом со входом по электронным картам, ему нужно чтобы вы написали программу, которая показывала в каком порядке сотрудники входили и выходили из офиса. Определение сотрудника происходит по id. Напишите функцию, которая на вход принимает кортеж и случайный элемент (id), его можно придумать самостоятельно. Требуется вернуть новый кортеж, начинающийся с первого появления элемента в нем и заканчивающийся вторым его появлением включительно. Если элемента нет вовсе – вернуть пустой кортеж. Если элемент встречается только один раз, то вернуть кортеж, который начинается с него и идет до конца исходного.

```python
def get_entry_exit_slice(tpl, element_id):
    indices = [i for i, x in enumerate(tpl) if x == element_id]
    num_occurrences = len(indices)
    
    if num_occurrences < 1:
        return tuple()
    
    if num_occurrences == 1:
        first_index = indices[0]
        return tpl[first_index:]
    
    if num_occurrences >= 2:
        first_index = indices[0]
        second_index = indices[1]
        return tpl[first_index : second_index + 1]

print(get_entry_exit_slice((1, 2, 3), 8))
print(get_entry_exit_slice((1, 8, 3, 4, 8, 8, 9, 2), 8))
print(get_entry_exit_slice((1, 2, 8, 5, 1, 2, 9), 8))
```

## Выводы

Функция `get_entry_exit_slice()` определяет индексы вхождений заданного элемента в кортеже. Если элемент отсутствует, возвращается пустой кортеж. Если элемент встречается один раз, возвращается срез от первого вхождения до конца. При двух и более вхождениях возвращается срез между первым и вторым вхождением, что соответствует задаче отслеживания входа и выхода.

Задача: Напишите функцию sum_even_numbers, которая принимает список элементов. Функция должна найти и вернуть сумму всех четных целых чисел в этом списке, игнорируя нечетные числа и любые другие типы данных (например, числа с плавающей точкой или строки).

```python
def sum_even_numbers(number_list):
    total_sum = 0
    for number in number_list:
        if isinstance(number, int) and number % 2 == 0:
            total_sum += number
    return total_sum

list_a = [10, 5, 2, 1, 8, 3]
result_a = sum_even_numbers(list_a)
print(result_a)

list_b = [1, 3, 5, 7, 9]
result_b = sum_even_numbers(list_b)
print(result_b)

list_c = [-4, 0, 11, -6, 1]
result_c = sum_even_numbers(list_c)
print(result_c)
```
