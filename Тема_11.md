## Лабораторная работа №2
### Класс итератор с гибкой настройкой и удобными применением

```python
class CountDown:
    def __init__(self, start):
        self.count = start + 1

    def __iter__(self):
        return self

    def __next__(self):
        if self.count <= 0:
            raise StopIteration
        self.count -= 1
        return self.count

if __name__ == "__main__":
    counter = CountDown(5)
    for i in counter:
        print(i)
```
### Результат.
![Меню](pic/pic2.png)

## Выводы

Создан собственный класс-итератор `CountDown`, реализующий протокол итерации через методы `__iter__` и `__next__`. Итератор принимает начальное значение, отсчитывает вниз до 0 включительно и завершает итерацию с помощью `StopIteration`. В отличие от простого итератора списка, этот класс даёт полную гибкость: можно легко изменить логику (например, добавить шаг, направление, условия остановки), что делает его удобным для нестандартных задач.

## Лабораторная работа №3
### Генератор списка

```python
a = [i ** 2 for i in range(1, 6)]
print(a)

for i in a:
    print(i)

print(iter(a))
for i in a:
    print(i)
```
### Результат.
![Меню](pic/Lpic3.png)

## Выводы

Продемонстрировано использование генератора списка (list comprehension). Переменная `a` сразу создаётся как готовый список квадратов чисел от 1 до 5. Такой объект поддерживает многократную итерацию: после первого прохода данные остаются в памяти, и по нему можно пройтись снова. Функция `iter(a)` возвращает объект итератора списка, что подтверждает: список — итерируемый объект, но сам по себе не является итератором.

## Лабораторная работа №4
### Выражения генераторы

```python
b = (i ** 2 for i in range(1, 6))
print(b)  # выводит не числа, а сам генератор списков

print('first')
for i in b:
    print(i)

print('second')
# из-за особенностей выражения генераторов,
# они не будут выводиться больше одного раза
for i in b:
    print(i)
```
### Результат.
![Меню](pic/pic4.png)

## Выводы

Продемонстрировано генераторное выражение `(i ** 2 for i in range(1, 6))`. В отличие от генератора списка, оно создаёт не список, а ленивый генератор-итератор. При первом проходе выводятся значения 1, 4, 9, 16, 25. При повторной попытке итерации ничего не выводится, т.к. генератор уже исчерпан — это ключевое отличие генераторных выражений от списков: они одноразовые и не хранят все значения в памяти.

## Лабораторная работа №5
### Такой же счетчик, как и в первом задании, только это генератор и использует yield

```python
def countdown(count):
    while count >= 0:
        yield count
        count -= 1

if __name__ == "__main__":
    counter = countdown(5)
    for i in counter:
        print(i)
```
### Результат.
![Меню](pic/pic5.png)

## Выводы

Реализована функция-генератор `countdown()`, использующая ключевое слово `yield`. При вызове она возвращает объект-генератор, который при итерации последовательно выдаёт числа от заданного значения до 0 включительно. Такой подход экономит память (не создаётся список), а значения генерируются по мере необходимости. Это аналог второго задания, но реализованный через генератор, а не через класс.

## Самостоятельная работа №1
### Вас никак не могут оставить числа Фибоначчи, очень уж они вас заинтересовали. Изучив новые возможности Python вы решили реализовать программу, которая считает числа Фибоначчи при помощи итераторов. Расчет начинается с чисел 1 и 1. Создайте функцию fib(n), генерирующую n чисел Фибоначчи с минимальными затратами ресурсов. Для реализации этой функции потребуется обратиться к инструкции yield (Она не сохраняет в оперативной памяти огромную последовательность, а дает возможность “доставать” промежуточные результаты по одному). Результатом решения задачи будет листинг кода и вывод в консоль с числом Фибоначчи от 200.

```python
def fib(n):
    a, b = 1, 1
    for _ in range(n):
        yield a
        a, b = b, a + b



print("Первые 10 чисел Фибоначчи:")
for i, num in enumerate(fib(10), 1):
    print(f"{i}-е: {num}")

fib_200 = list(fib(200))[-1]
print("\n200-е число Фибоначчи:")
print(fib_200)
```

![Меню](pic/pic6.png)

## Выводы

Реализована функция-генератор `fib(n)`, которая с помощью `yield` последовательно выдаёт первые n чисел Фибоначчи, начиная с 1, 1. Генератор не сохраняет всю последовательность в памяти, а вычисляет каждое следующее число по мере запроса — это обеспечивает минимальное потребление ресурсов даже при больших n. Для получения 200-го числа последовательность материализуется в список и берётся последний элемент. Вывод подтверждает корректность работы и высокую эффективность подхода.

def fib(n):
    a, b = 1, 1

## Общие выводы по теме
Итераторы и генераторы — мощные инструменты Python для эффективной и экономной работы с последовательностями данных. Итераторы позволяют последовательно обходить элементы коллекций, реализуя протокол `__iter__` и `__next__`. Генераторы (функции с `yield` и генераторные выражения) создают итераторы «на лету», не загружая всю последовательность в память, что критически важно при работе с большими или бесконечными наборами данных. Генераторы списков удобны для небольших объёмов и многократного использования, а генераторные выражения и функции-генераторы — идеальны для ленивых вычислений и экономии ресурсов. Правильный выбор между этими инструментами значительно повышает производительность и читаемость кода.
